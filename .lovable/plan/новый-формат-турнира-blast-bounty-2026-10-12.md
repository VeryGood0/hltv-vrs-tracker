# Новый формат турнира: BLAST Bounty

## Что строим

Новый режим турнира `blast_bounty` (32 команды, Single Elimination, BO3, финал BO5) с уникальными механиками:

1. **Баунти-экономика**
   - Топ-16 по посеву получают стартовую награду «за голову»: Топ-4 — $60,000, 5–8 — $40,000, 9–12 — $25,000, 13–16 — $15,000.
   - Посевы 17–32 («охотники») начинают с $0.
   - При победе: 50% баунти проигравшего уходит победителю на «банк» (гарантированная выплата), остальные 50% добавляются к баунти самого победителя.

2. **Драфт соперников (Draft Show)**
   - Сетка не фиксирована заранее. Перед каждым раундом команды с низким посевом по очереди выбирают себе соперника из пула высоких посевов.
   - Пользователь может выбирать вручную или нажать «Авто-драфт» (аутсайдеры выбирают соперника с максимальным баунти / случайно).

3. **Наследование посева**
   - Победивший аутсайдер получает номер посева побеждённого фаворита на следующий раунд.

4. **Ставки на LAN-финале (Final 8)**
   - Начиная с четвертьфинала команда может поставить часть своего банка на свою победу (не больше банка соперника). Победитель забирает всю ставку.

5. **Этапы**: Онлайн-стадия (1/16, 1/8 — из 32 до 8 команд) и LAN-финал (QF, SF, Final BO5).

## Изменения в коде

- `src/app/types.ts` — новый режим `blast_bounty` в `TournamentMode`; типы `BountyTeamState` (seed, bounty, bank) и поле `bountyState` в `TournamentState`.
- `src/app/utils/blastBounty.ts` (новый) — создание турнира, стартовые баунти, логика драфта, обработка результата матча (50/50 split, наследование посева, вейджеры), продвижение раундов.
- `src/app/utils/tournament.ts` — ветка `blast_bounty` в `createCustomTournament` (делегирует в blastBounty.ts).
- `src/app/components/CreateTournamentModal.tsx` — пресет «BLAST Bounty 2026» (32 команды, S-Tier, $500,000) и карточка формата; блокировка создания, пока не выбраны все 32 команды.
- `src/app/components/TournamentHub.tsx` — рендер режима: панель баунти (таблица команд с баунти/банком/посевом), экран драфта между раундами, обработка результатов через blastBounty-логику, вейджеры на Final 8.
- `src/app/components/BlastBountyView.tsx` (новый) — таблица баунти + UI драфта + UI ставок.
- Тесты: `src/app/utils/blastBounty.test.ts` — стартовые баунти по посевам, правило 50/50, наследование посева, лимит вейджера.

## Технические детали

- Матчи хранятся в существующем `playoffMatches` (poolKey r32_*/r16_*/qf*/sf*/final), чтобы переиспользовать PlayoffsStageView и симуляцию матчей.
- Баунти/банк/текущий посев — в `tournament.bountyState: Record<teamId, BountyTeamState>`.
- Драфт: раунд создаётся без пар; статус турнира «draft» — UI предлагает аутсайдерам (по возрастанию силы) выбрать соперника из оставшихся высоких посевов.
- Вейджер хранится на матче (`wagerA`, `wagerB`), применяется при фиксации результата.
