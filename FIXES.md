# Исправления турниров CS2

В этой версии исправлены создание турниров и отображение сеток.

- Состав участников сохраняется в указанном порядке посева; быстрые действия больше не подменяют выбранные команды всеми командами приложения.
- Полная сетка Single Elimination строится для 4–32 участников, включая неполные сетки с автоматическими проходами (bye) и корректное продвижение победителей. Опциональный матч за 3-е место получает проигравших полуфиналов.
- Double Elimination содержит верхнюю и нижнюю сетки и решающий reset-финал, если победитель нижней сетки выигрывает первый гранд-финал.
- Отрисовка плей-офф показывает дополнительные раунды крупных сеток и матчи нижней сетки.
- Круговой формат использует собственное расписание матчей, корректно показывает встречи, обрабатывает результаты, быстрый раунд и симуляцию всего турнира.
- «Чистая швейцарка» завершается итоговой таблицей без неожиданного создания плей-офф.
- Убрана лишняя панель «Турнирные сетки CS2 / Формат турнира» из экрана активного турнира: формат и участники выбираются при создании.
- Добавлены тесты логики построения сеток и расписания.

Проверка исходников выполнена через TypeScript transpile, а логику турнирных сеток дополнительно проверено отдельным Node.js сценарием. Полную сборку Vite/Vitest в этой среде запустить не удалось, потому что зависимости проекта не были установлены.
